# Distribution status

These archives are experimental bootstrap artifacts for issue #33. They prove
that Marionette's selected Racket dependencies can be assembled and launched
without a separate Racket installation; they do not yet implement the
Marionette language.

The repository package metadata declares MIT licensing. A production cutover
must add the project's canonical licence text and any Racket runtime notices
required for redistribution before the first non-experimental release.
