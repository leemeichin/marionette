## Walkthrough

### export_content (start)
Export the full WordPress site: posts, pages, and the entire media library.
Done when the WordPress XML export and a complete images archive exist locally and post counts match the live site.
- **Export verified complete** → convert_to_markdown
- **Exporter broken or archive incomplete** → manual_export

### manual_export
Fallback extraction: pull post content straight from the WordPress database and copy wp-content/uploads over SFTP.
- **Content and media recovered** → convert_to_markdown
- **Cannot recover everything** → reassess (**requires a human decision**)

### convert_to_markdown
Convert exported posts to Hugo markdown with front matter, and rewrite image links to the new static paths.
Done when every post builds under Hugo with images and internal links resolving.
- on entry: `convert_rounds += 1`
- **All posts render, images and links resolve** → build_theme (repeatable)
- **Fix conversion glitches and re-run** → convert_to_markdown (only if `convert_rounds < 5`; loops back; repeatable)
- **Conversion not converging** → reassess (only if `convert_rounds >= 5`; **requires a human decision**; repeatable)

### build_theme
Install and customise the Hugo theme until the site looks right in a local build: layout, typography, archives, RSS.
- on entry: `theme_rounds += 1`
- **Theme looks right locally** → preview_for_jo (repeatable)
- **Iterate on templates and styles** → build_theme (only if `theme_rounds < 5`; loops back; repeatable)
- **Theme work not converging** → reassess (only if `theme_rounds >= 5`; **requires a human decision**; repeatable)

### preview_for_jo
Deploy the Hugo site to a private staging URL and walk Jo through the design.
- on entry: `jo_rounds += 1`
- **Jo approves the design** → cutover (**requires a human decision**; repeatable)
- **Jo wants changes** → build_theme (only if `jo_rounds < 4`; **requires a human decision**; loops back; repeatable)
- **Design reviews not converging** → reassess (only if `jo_rounds >= 4`; **requires a human decision**; repeatable)

### cutover
Point the domain's DNS at the new Hugo hosting, leaving the WordPress install untouched as a fallback.
Done when DNS has propagated and the domain serves the Hugo site.
- on entry: `cutover_attempts += 1`
- **DNS updated and propagated** → verify_live (repeatable)

### verify_live
Spot-check the live domain: recent and old posts, images, RSS feed, and redirects for old WordPress permalinks.
- **Everything checks out** → retire_wordpress (repeatable)
- **Broken in production; roll DNS back and fix** → cutover (only if `cutover_attempts < 3`; loops back; repeatable)
- **Cutover keeps failing** → reassess (only if `cutover_attempts >= 3`; **requires a human decision**; repeatable)

### retire_wordpress
Take a final full backup of the WordPress database and files, archive it off-host, then decommission the old install and hosting.
- **Backup archived; WordPress decommissioned** → END (**requires a human decision**)

### reassess
The migration hit a wall somewhere; decide whether to change approach, get help, or shelve it while WordPress stays live.
- **Adjust approach and resume from conversion** → convert_to_markdown (**requires a human decision**; loops back; repeatable)
- **Shelve the migration; WordPress stays live** → END (**requires a human decision**; repeatable)
