# Session 2 notes (as given)

> We're adding a plugin system to our open-source CLI tool. Build the plugin API behind a feature flag first, then run a beta with a few community plugin authors. We'll iterate on their feedback but not forever — three rounds max, then we either ship what we have or cut the API surface down to just hooks. Either way the lead maintainer has to approve the final API before it's tagged in a release, because once it's public we're stuck supporting it.
