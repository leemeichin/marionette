## Walkthrough

### ingest (start)
Pull the nightly dumps from the vendor SFTP drop; vendor outages are expected and non-fatal.
- **Dump retrieved** → transform (repeatable)
- **Vendor outage, retry tomorrow night** → ingest (loops back; repeatable)

### transform
Normalize the dumps into the warehouse schema; mapping bugs surface here.
- **Transform clean** → publish (repeatable)
- **Mapping bugs found, reconcile and patch** → reconcile (only if `patch_cycles < 5`; loops back; repeatable)
- **Five patch cycles exhausted, page the on-call** → END (only if `patch_cycles >= 5`; **requires a human decision**; repeatable)

### reconcile
Reconcile row counts against the source and patch the mapping.
- on entry: `patch_cycles += 1`
- **Patched, run the transform again** → transform (repeatable)

### publish
Publish the curated tables, write the audit trail, and notify downstream consumers within the 24-hour freshness SLA.
- otherwise → END
