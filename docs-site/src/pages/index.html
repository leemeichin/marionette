marionette

Write down how a project should run, let an AI agent handle the routine steps, and keep important decisions with people.

Marionette turns a plain-text project plan into a set of steps that an AI agent can follow. The plan describes the stages of the work, the choices between them, and any rules for moving forward. Marionette checks the plan for missing or impossible paths before work begins. A choice marked @human always requires a person: the tool will refuse to let an agent take it.

You can write the plan yourself or ask an AI to draft one from your notes. Either way, the file stays readable, reviewable, and stored with your project. Marionette also records what happened and why, so you can see how the project reached its current stage.

The parts of a Marionette project
PartWhat it does
Plan fileDescribes the work, the choices, and the decisions reserved for people
CheckerFinds missing steps, dead ends, and retry paths that may never finish
RunnerShows the agent what to do next and records each decision

The original request goes at the top. Each section then describes one stage of work and what can happen next. This example allows up to five attempts to improve checkout. A person decides whether to launch or return to research, and every route has a clear ending.
