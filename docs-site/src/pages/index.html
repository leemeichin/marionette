marionette

Write down how a project should run, let an AI agent handle the routine steps, and keep important decisions with people.

A Marionette plan is a plain-text file: the stages of the work, the choices between them, and the rules for moving forward. Marionette checks the plan for missing or impossible paths before work begins, records every decision and why it was made, and a choice marked @human always requires a person — the tool refuses to let an agent take it.

Try it right here. The editor below runs the real compiler and walker in your browser: pick an example, edit it and watch it re-check as you type, then take the choices yourself — as the agent, or as the human the plan reserves decisions for.
