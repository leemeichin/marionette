marionette

Give an AI agent a clear route through a project—and keep the decisions that matter with people.

A Marionette plan is a small text file describing the stages of a project, the routes between them, and the rules for moving forward. The compiler catches missing and impossible paths before work begins.

1 · Write the route

Describe the work in readable stages, with explicit next steps.

2 · Let the agent work

The agent receives one bounded assignment at a time and records why it moved on.

3 · Hold the gates

Mark a decision @human and the agent cannot take it for you.

Try a plan

Start with “hello world”, then load the issue-to-PR loop. The editor uses the real compiler and highlights the plan as you type; the panel on the right shows the route and lets you walk it.
